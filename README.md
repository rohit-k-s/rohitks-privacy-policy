# rohitks-privacy-policy

Privacy policies and support pages for Rohit Kumar Singh's apps, published with GitHub Pages at https://rohit-k-s.github.io/rohitks-privacy-policy/.

| App | Privacy policy | Support |
| --- | --- | --- |
| GlugGlug | https://rohit-k-s.github.io/rohitks-privacy-policy/glugglug/ | https://rohit-k-s.github.io/rohitks-privacy-policy/glugglug/#support |

`glugglug/index.html` is generated from the app repository (`docs/launch/privacy-policy.md`, the same text as the app) by `python3 tool/site/policy_page.py <this checkout>`. Don't edit it by hand; change the policy there, re-run, and push here.
